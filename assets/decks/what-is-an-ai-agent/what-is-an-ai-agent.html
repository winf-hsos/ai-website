chatbot vs. agent

a chatbot only answers, while an agent acts on its own.
Oben: Prompt, Antwort, und der nächste Schritt liegt bei mir. Unten: Ich gebe ein Ziel, und das Modell ruft selbst Werkzeuge auf, sieht das Ergebnis an und macht weiter, bis das Ziel erreicht ist. Unter der Haube dasselbe Sprachmodell; der Unterschied ist, was drumherum gebaut ist.

a working definition

an AI agent runs tools in a loop
to achieve a goal.
after simon willison, september 2025 · anthropic: agents are "LLMs using tools based on environmental feedback in a loop"
Drei Teile, die wir gleich einzeln ansehen: das Sprachmodell, die Werkzeuge, die Schleife. „Goal“ heißt: Die Schleife hört auf, wenn das Ziel erreicht ist.

workflow or agent?

anthropic, building effective agents (2024)
Nicht alles, wo KI drinsteckt, ist ein Agent. Beide Beispiele kommen aus dem Einkauf: Auch im Workflow arbeitet ein Sprachmodell (es liest die Rechnung), aber die Schritte stehen fest. Beim Agenten weiß vorher niemand, welche Lieferanten er findet, welche Angebote er einholt und wie oft er nachsehen muss. Ein Workflow folgt festen Schritten, die jemand vorher festgelegt hat; ein Agent entscheidet selbst. Anthropics Rat: so einfach wie möglich, Agenten nur, wo es nötig ist.

the goal and the model

what we saw: a few sentences, a photo, a text file.
Das Modell allein kann nur Text erzeugen. Es kann keine Datei öffnen und keine Webseite laden.

tools

what we saw: it listed the folder, downloaded papers, wrote files.
Das Modell schreibt nur auf, welches Werkzeug es mit welchen Angaben aufrufen will. Ausgeführt wird das vom Programm auf meinem Rechner. Werkzeuge sind die Hände des Agenten.

the loop

what we saw: it read a source, then decided what to do next.
Das Muster heißt in der Forschung ReAct (Yao u. a., 2022): denken, handeln, Ergebnis ansehen, weiter. Der Kern jedes Agenten.

context window

what we saw: "context 14 %" in the corner of the app.
Alles, was der Agent „weiß“, steht in diesem Fenster: die Aufgabe, jede Werkzeugantwort, jede Zwischenüberlegung. Ist es voll, muss er zusammenfassen oder vergessen. Thema einer späteren Sitzung.

plan and instructions

what we saw: "show me your plan. wait for my go."
Der Plan ist ein Werkzeug wie jedes andere: Der Agent schreibt sich eine Liste und hakt ab. Skills und agents.md sind Anweisungen in Textdateien, die er bei Bedarf liest. So arbeiten auch meine Agenten für die Lehre.

sub-agents

what we saw: "research by 8 agents", and nobody asked for that.
Der Aha-Moment von letzter Woche: Wir haben es nicht verlangt. Parallel geht schneller, und jede Kopie hat ein frisches Kontextfenster.

all of it together

the model decides, the tools carry it out, and the loop keeps running until the goal is reached.
Alles zusammen. Wenn ihr euch eine Sache merkt, dann die gelbe Schleife.

the harness

the same model in a different harness is a different agent.
Alles, was wir eben um das Modell herum gezeichnet haben, heißt Harness, wörtlich das Geschirr, mit dem man ein Pferd vor den Wagen spannt. Das Modell liefert die Kraft, der Harness lenkt sie. Claude Code, Codex und OpenCode sind Harnesses; das Modell darin lässt sich oft austauschen. Wie gut ein Agent ist, hängt deshalb nicht nur vom Modell ab, sondern auch davon, welche Werkzeuge, welchen Kontext und welche Regeln der Harness ihm gibt.

models and apps

Ein Modell steckt in vielen Produkten. Die Grenzen verschwimmen: Auch ChatGPT kann inzwischen suchen, Code ausführen, Dateien erzeugen. Modellnummern lassen wir weg, sie veralten im Monat. OpenClaw läuft rund um die Uhr auf einem eigenen Rechner und wird über Messenger gesteuert.

why now?

the length of tasks agents can finish doubles every few months.
METR, time horizons · kwa et al. 2025 · software tasks
Zwischen 2019 und 2024 verdoppelte sich die Länge etwa alle sieben Monate, seit 2023 eher alle vier (METR, Januar 2026). Es sind Programmieraufgaben; ob das auf andere Arbeit übertragbar ist, ist offen. Genau das diskutieren wir in „agents and work“. Achse linear in Stunden.

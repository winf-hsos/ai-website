a file full of numbers

Ein Modell ist kein Programm mit Regeln und keine Datenbank mit Texten, sondern eine sehr lange Liste von Zahlen, die Parameter oder Gewichte heißen. Wie diese Zahlen entstehen, ist Thema von „Neural Networks“ und „Training a Large Language Model“.

how many values fit into a few bits?

every extra bit doubles the number of values a weight can take.
Ein Bit kennt zwei Zustände, zwei Bit vier, vier Bit sechzehn. Mit 16 Bit kann jedes Gewicht einen von über 65.000 Werten annehmen, also sehr fein abgestuft sein; mit 4 Bit nur einen von 16.

rounding one weight

simplified: 16 evenly spaced values between −1 and +1
Ein Gewicht von 0,8710, die rosa Marke. Mit 16 Bit liegt der nächste erlaubte Wert praktisch darauf. Mit 4 Bit gibt es nur 16 erlaubte Werte, das Gewicht wird zu 0,867. Mit drei Werten bleibt nur −1, 0 oder +1, es wird zu 1; solche Modelle gibt es wirklich (etwa BitNet b1.58), sie werden von Anfang an so trainiert. Mit einem Bit bleibt nur noch das Vorzeichen.

Mit 4 Bit bleiben die Gewichte nahe am Original, das Modell verhält sich fast wie vorher. Mit drei Werten werden zwei der vier Gewichte zu null; ein Modell, das nachträglich so grob gerundet wird, verliert viel. Deshalb ist 4 Bit für Modelle auf dem Laptop ein verbreiteter Kompromiss.

why 2.4 GB?

4 billion numbers × 16 bits = 8 GB
4 billion numbers × ~4.5 bits = 2.4 GB
fewer bits per number: quantization.
Die Zahlen werden gerundet gespeichert, damit das Modell in den Arbeitsspeicher passt. Das kostet etwas Qualität und spart viel Platz. Im Dateinamen steht, wie stark gerundet wurde, etwa Q4 für rund vier Bit je Zahl.

what happens when you press enter

bigger models are slower, because every token passes through more numbers.
Inferenz heißt: das Modell anwenden, nicht trainieren. Beim Laden wandert die Datei in den Arbeitsspeicher oder Grafikspeicher. Jedes neue Token kostet einen Durchgang durch alle Parameter; darum hängen die Tokens pro Sekunde an Speicher und Rechenleistung.

how big is big?

parameters as published by the providers; log scale
Was auf dem Laptop läuft, ist mehrere hundertmal kleiner als die großen offenen Modelle. Die Größe der geschlossenen Spitzenmodelle hinter ChatGPT, Claude oder Gemini veröffentlichen die Anbieter nicht.

local and cloud

the same harness can talk to a model on your laptop.
see also: the harness
An die Zeichnung „where does it run?“ aus „AI Agents“ erinnern: Der gestrichelte Kasten „a local LLM“ ist das, was wir eben gestartet haben. Ein Agent kann statt des Cloud-Modells ein lokales benutzen, mit allen Folgen für Qualität und Tempo.

open weights, closed weights

open
download it, run it, change it.
gemma, qwen, llama, mistral, deepseek, gpt-oss
closed
use it as a service.
gpt, claude, gemini
open weights is not the same as open source: the training data usually stays secret.
Offen heißt meist nur, dass die Gewichte frei sind. Wie das Modell entstand und womit, bleibt oft verborgen; ganz offene Modelle wie Olmo legen auch Daten und Trainingscode offen. Die Lizenzen unterscheiden sich, manche schränken die kommerzielle Nutzung ein.
would you paste a farm's customer list into a cloud chatbot?
  1. yes
  2. only with a contract
  3. only into a local model
  4. never
Kein richtig oder falsch. Die Verteilung ist der Einstieg ins Gespräch über personenbezogene Daten, Verträge zur Auftragsverarbeitung und darüber, wann sich ein lokales Modell lohnt.

when local makes sense

your data must not leave the building.
you need it offline, in a barn, on a tractor or on your phone.
you use it so much that tokens get expensive.
and you accept a smaller, slower model in return.
on a phone: google ai edge gallery, an app that runs small gemma models offline on android and ios
Zur zweiten Zeile: Googles App AI Edge Gallery (Android und iOS) lädt kleine Gemma-Modelle aufs Telefon und beantwortet Fragen ohne Netz. Die vierte Zeile ist der Preis für die ersten drei. Dazu kommen Hardware und Wartung: Wer ein Modell selbst betreibt, muss es auch aktuell halten.

key takeaway

a language model is a file full of numbers that runs on your own laptop without the internet; its size decides how good, how fast and how hungry it is.
Das Modell, das eben offline geantwortet hat, ist nichts anderes als diese Datei. Alles, was es kann, steckt in den Zahlen darin.

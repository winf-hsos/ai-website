step 1 · research

We are the master's module "Applications of Artificial Intelligence". Help us build a knowledge base on the history of AI. Inputs: - a photo of our pinboard: milestones the students of this course know - milestones.md: AI milestones that students of this course collected a year ago Tasks: - find reliable sources for every milestone, and research further important milestones yourself - download every source and save it - read each source and extract the key facts: what? who? where? when? — and so what? - store them in a structured knowledge base as Markdown, one file per milestone, with its source and its origin: last semester, today's students, or agent - write all errors you find in milestones.md to an Excel list - pinboard cards you cannot verify go to a list "still to check" First read everything and show me your plan. Wait for my go.
Knopf klicken, in Claude Code einfügen, das Foto hängt schon an. Vorher: das Google Doc aus dem WS 25/26 live als Markdown exportieren, als milestones.md in einen leeren Ordner legen und Claude Code dort starten. Das ist alles, was wir ihm sagen. Den Rest entscheidet er — welche Dateien, welcher Aufbau, welche Werkzeuge. Den Plan laut vorlesen, dann mit „go“ freigeben. Danach Claude Code auf den Beamer und laut mitlesen, was er tut: Er liest die Datei, sieht das Foto an, sucht Quellen, lädt sie herunter, liest sie und legt die Wissensbasis an. Nicht verraten: dass er die Quellen parallel mit Subagenten bearbeiten kann und dass wir am Ende veröffentlichen. Zeit im Blick behalten: Dauert es zu lange, per Zuruf auf die wichtigsten Meilensteine begrenzen. Zwischendurch einen Blick in die Wissensbasis werfen: Wie sieht eine Datei aus?

step 3 · quiz

Add a quiz to the app, so visitors can test what they learned about the history of AI. - 50 interesting questions, based only on the knowledge base - 4 answer options per question, exactly one of them correct - the wrong options must be plausible, not silly - after each answer: right or wrong, the correct answer, and a link to the matching entry on the timeline - questions in random order, a score at the end - same design as the timeline; must work on phones Show me three example questions first. Wait for my go.
LIVE-MOMENT. Dritter Prompt. Drei Beispielfragen vorlesen und die Studierenden raten lassen — sind sie gut? Zu leicht? Dann „go“. Wenn das Quiz steht: am Beamer eine Runde gemeinsam spielen. Die richtigen Antworten kommen aus der Wissensbasis; die falschen hat das Modell erfunden — plausibel falsch zu sein ist eine eigene Fähigkeit.

bonus · guided mode

Add a guided mode to the app: a narrator tells the history of AI, and the app follows along. - write an engaging story from the milestones, based only on the knowledge base - choose a fitting narrator voice from the OpenAI text-to-speech API; the API key is in the environment variable OPENAI_API_KEY - create the audio in advance — the app itself never calls the API - while the narrator speaks, the app opens the matching milestone on the timeline by itself, no clicks needed - the user can pause, skip and leave the guided mode at any time - say in the app that the voice is AI-generated - never write the API key into the app or into any file Show me the outline of the story and the voice you chose first. Wait for my go.
BONUS, nur wenn die Zeit reicht. Den API-Schlüssel VOR der Sitzung als Umgebungsvariable OPENAI_API_KEY setzen, bevor Claude Code startet — nie live eintippen, nie die Variable anzeigen lassen, solange der Beamer läuft. Die Stimme erzeugt der Agent einmal vorab als Audiodateien; die App selbst braucht keinen Schlüssel, deshalb kann sie später öffentlich sein. Gliederung und Stimmwahl vorlesen, dann „go“. Danach den Guided Mode am Beamer abspielen. Anknüpfungspunkt: Text, Stimme, Timing — drei Modelle bzw. Werkzeuge in einer Schleife. Die Kennzeichnung als KI-Stimme ist keine Kür: Der EU AI Act verlangt sie für künstlich erzeugte Inhalte.

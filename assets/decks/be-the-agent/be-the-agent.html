Im Experiment „A Brief History of AI“ haben wir einem Agenten zugesehen. Jetzt spielen wir einen nach, ohne Rechner, damit sichtbar wird, wer eigentlich was tut: das Sprachmodell, die Werkzeuge und das Programm dazwischen.

seven roles

Gruppen zu sieben; bei sechs übernimmt eine Person Search und Web, bei fünf zusätzlich eine Person Files und Calculator. Rollenkarten austeilen. Das Model sitzt mit dem Stapel in der Mitte, die vier Werkzeuge an eigenen Tischen, der Harness läuft hin und her, der Observer schreibt mit.

four kinds of cards

Das Model schreibt nur drei Sorten Karten: Überlegungen, Werkzeugaufrufe und am Ende die Antwort. Die vierte Sorte, das Ergebnis, kommt immer von einem Werkzeug. Pink ist alles, was vom Model kommt, grau alles, was ein Werkzeug zurückgibt. Das Beispiel ist der Anfang von Aufgabe 1: Das Model weiß nicht, welche Dateien es gibt, und sieht erst nach. Bei den drei Punkten fehlen zwei Karten, read_file("fields") und das Ergebnis mit der Tabelle der Felder.

the rules

the model sees only its stack, and nobody talks to it.
the harness carries every card to the right tool and brings the result back.
a tool does exactly what the card says, nothing more.
one card at a time, until the model writes ANSWER:.
Die Regeln stehen auch auf den Rollenkarten. Wichtig ist die dritte: Ein Werkzeug repariert nie einen Aufruf und rät nie, was gemeint war, auch wenn es offensichtlich ist.

the system card

search("words")
finds web pages and returns their titles
open("title")
returns the full text of one web page
list_files()
returns the names of all farm files
read_file("name")
returns the text of one farm file
calculator("expression")
calculates, e.g. calculator("4.5 * 100")
write_file("name", "text")
saves a text as a new farm file
this is everything the model knows about its tools.
Das ist alles, was das Model über seine Werkzeuge weiß. Steht etwas nicht auf dieser Karte, gibt es das für das Model nicht. Welche Dateien es gibt, steht nicht darauf: Das Model muss erst nachsehen, wie ein echter Agent, der einen Ordner auflistet. Die Wetterdatei taucht dann in der Liste auf, aber keine Aufgabe sagt, dass man sie braucht.

task 1 · about 5 minutes

how large is the field long acre, and what grows on it this year?
Aufwärmrunde mit zwei Werkzeugaufrufen: erst die Dateien auflisten, dann die richtige lesen. Danach fragen: Hat ein Model zuerst gesucht oder einen Dateinamen geraten, statt nachzusehen?

task 2 · swap roles · about 12 minutes

how much nitrogen may we still apply to long acre this spring? give the total in kg N for the whole field.
Vorher Rollen tauschen. Lösung 630 kg N: Bedarf 180 aus dem Leitfaden 2026 minus Nmin 40, mal 4,5 ha. Die Suche liefert auch das Archiv von 2009 mit 210.

task 2 · compare

which nitrogen requirement did your model use, and where did it come from?
Frage in die Runde, jede Gruppe nennt ihren Wert. 210 stammt aus dem Archiv von 2009. Woran hätte das Model das erkennen können? Genau dieses Problem haben echte Agenten mit veralteten Quellen.

task 3 · if there is time

plan the first nitrogen application on long acre: how much of which product do we need, and can we spread it on 10 february?
Die Falle steckt in der Wetterdatei: Am 10. Februar ist der Boden den ganzen Tag gefroren, frühestens am 11. Harnstoff reicht nicht, im Lager sind nur 500 kg. Lösung: 252 kg N in der ersten Gabe, gut 933 kg Kalkammonsalpeter.

→

→

→

→

the harness
→
harness: the program that runs the tools
RESULT:
→
observation, added to the context

→

Zeile für Zeile aufdecken und je einmal fragen: Wo habt ihr das eben erlebt? Search, Web, Files und Calculator entsprechen Websuche, Abruf einer Seite, Dateisystem und einem Programm, das rechnet.

key takeaway

an AI agent is a large language model (LLM) that can only write text; everything it does in the world happens through tools that the harness runs for it.
Das Model hat keine Datei geöffnet und nichts gerechnet; es hat nur geschrieben, und alle anderen haben es ausgeführt. Deshalb weiß es nur, was auf seinem Stapel liegt.
